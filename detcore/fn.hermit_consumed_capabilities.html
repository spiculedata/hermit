pub const fn hermit_consumed_capabilities(

Expand description

The capabilities a backend reports, less the ones Detcore does not consume yet. supports_guest_memory_compare_exchange (DBT, Reverie ABI 8) has no Detcore consumer until the robust-futex owner-death change lands (https://github.com/rrnewton/hermit/pull/4277), and the DBT runtime does not install the exchange, so Hermit reports it as false for every backend.
